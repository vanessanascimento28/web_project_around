# 📸 EUA Afora – Sprint 6

Projeto desenvolvido durante a Sprint 6 do curso Web Development da TripleTen. O desafio foi criar uma **página interativa e responsiva**, com **estrutura BEM**, **edição de perfil via pop-up** e primeiros passos com **JavaScript Vanilla**.

A proposta simula uma galeria de fotos dos Estados Unidos, com foco em layout adaptável, boas práticas de CSS e comportamento dinâmico da interface.

**🎯 Objetivo do Projeto**

- Consolidar o uso de **HTML, CSS e JavaScript** para criar uma página funcional e interativa;
- Trabalhar com **layouts responsivos** para múltiplos dispositivos (mobile, tablet e desktop);
- Implementar **pop-ups** que interagem com os dados exibidos na página;
- Praticar a **estruturação de código com BEM**;
- Iniciar o uso de **ramificações Git** organizadas por feature.

**✅ Resultado**

A aplicação foi concluída e publicada no GitHub Pages. A funcionalidade de edição de perfil via pop-up está totalmente funcional, e o layout responde bem às diferentes larguras de tela. O maior aprendizado foi integrar pela primeira vez HTML, CSS e JavaScript em uma única aplicação funcional.
O maior desafio foi lidar com o JavaScript, uma linguagem totalmente nova para mim.

**🛠 Tecnologias Utilizadas**

- HTML5  
- CSS3 (com Flexbox e Media Queries)  
- JavaScript (ES6)  
- Metodologia BEM  
- Git e GitHub  
- GitHub Pages  

**⚙️ Funcionalidades**

- ✅ Layout responsivo com breakpoints para 320px, 768px e 1280px  
- ✅ Galeria de 6 cartões com imagens e nomes personalizados  
- ✅ Animações e efeitos de hover nos botões  
- ✅ Pop-up para editar o nome e descrição do perfil  
- ✅ Inputs pré-preenchidos com os dados atuais  
- ✅ Atualização dinâmica das informações no DOM  
- ✅ Organização de código com BEM e pastas modulares  
- ✅ Estrutura de ramificações Git com feature/ e hotfix/  
- ✅ Estilização com `text-overflow: ellipsis` para textos longos  

**🚀 O que aprendi com esse projeto**

- Como manipular o DOM com `addEventListener`, `querySelector`, `textContent` e `value`  
- Criar pop-ups funcionais com CSS + JS  
- Responsividade com `media queries` e uso de `object-fit` para imagens  
- Boas práticas de nomenclatura e estruturação com **BEM**  
- Fluxo de trabalho com **Gitflow** (main, develop, feature, hotfix)  
- Publicar no **GitHub Pages**

**🔧 Melhorias Futuras**
